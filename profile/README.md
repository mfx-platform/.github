## MFX Hub

Hosted trading terminals for your own broker accounts, behind one signed API: market data,
execution, account state and a live event stream. MFX Hub runs the terminals; you keep your broker,
your account and your strategy.

**Start here:** [docs.mfxhub.com](https://docs.mfxhub.com) · [mfxhub.com](https://mfxhub.com)

| Repository | What it is |
|---|---|
| [mfx-sdk-python](https://github.com/mfx-platform/mfx-sdk-python) | The typed Python client: `pip install mfx-sdk` |
| [mfx-kb](https://github.com/mfx-platform/mfx-kb) | Guides and runnable samples, run against our development environment in CI |

SDKs for TypeScript, .NET and Java are on the way, tested against the same shared suite as the
Python one.

**Security:** report a vulnerability privately through a repository's *Report a vulnerability*
button, or to security@mfxhub.com. **Support:** support@mfxhub.com.
